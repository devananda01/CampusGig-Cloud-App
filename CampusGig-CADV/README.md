# CampusGig

CampusGig is a cloud-based web application that connects students who need help completing tasks with students looking for short-term gig opportunities within their campus community.

The application is built using AWS cloud services with a serverless backend architecture.

---

## Features

### Authentication

- User Registration
- User Login
- Forgot Password
- Password Reset
- JWT Authentication using Amazon Cognito

### Applicant Features

- Browse available tasks
- Search tasks
- Filter tasks by category
- View task details
- Apply for tasks
- Edit application
- Withdraw application

### Poster Features

- Create tasks
- Edit tasks
- Delete tasks
- Accept or reject applications
- Prevent task owners from applying to their own tasks

### Profile Management

- Update profile information
- Upload profile picture

---

## AWS Services

- Amazon Cognito – User authentication and authorization
- Amazon API Gateway – REST API endpoints
- AWS Lambda – Serverless backend
- Amazon DynamoDB – User profile storage
- Amazon RDS (MySQL) – Task and application data
- Amazon S3 – Profile image storage
- Amazon SES – Email notifications for application status updates
- AWS Amplify – Frontend hosting
- Amazon CloudWatch – Application monitoring and logging
